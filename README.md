## Features

- Live TMDB catalog (search, trending, details)
- Official YouTube trailers only
- Watch providers via TMDB / JustWatch
- Watchlist in `localStorage`

## Setup

1. Get a key at [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api)
2. Set `TMDB_API_KEY` on the Vercel project, or paste it in the on-site setup screen (browser only)

| Layer | Tech |
