# MovieHub

Movies, series, and anime for DarkNova. Catalog data comes from Prexzy. No API key.

- Home: trending, movies, series, and the fresh catalog
- Search across movies and series
- Anime home, genres, weekly schedule, synopsis, and episode list
- Official YouTube trailers where the catalog has them
- My list stays in the browser

Deploy on Vercel. The `/api/prexzy` function proxies the allowed catalog routes.
